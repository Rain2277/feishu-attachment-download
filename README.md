# 飞书多维表格插件 · 附件批量下载（自定义命名 + ZIP 打包）

在飞书多维表格的**边栏插件**中运行。打开插件后，勾选要下载的附件字段，设置命名规则，一键把所有附件下载并重命名、打包成 ZIP。

无需注册飞书开放平台应用，直接把本插件的网页地址添加到多维表格的「自定义插件」即可运行。

## 功能

- ✅ 多附件字段勾选，一键批量下载
- ✅ 自定义命名规则，支持变量：
  - `{原文件名}` 原始文件名（含扩展名，如 report.pdf）
  - `{文件名}` 原始文件名（不含扩展名）
  - `{扩展名}` 扩展名（不含点）
  - `{序号}` 全局序号，默认 4 位补零（`{序号:3}` 可指定位数）
  - `{日期}` 打包当天日期（YYYY-MM-DD）
  - `{任意字段名}` 表格中其他字段的值（文本取文本，多值以顿号连接）
- ✅ 命名自动去重（同名追加 `_2`、`_3`），自动过滤非法字符
- ✅ 记录范围：全部记录 / 当前视图可见记录
- ✅ 实时预览命名效果、进度展示、单文件失败不影响整体

示例模板：`{姓名}_{日期}_{序号}` → `张三_2026-09-24_0001`

## 快速开始（本地开发）

要求：Node.js ≥ 18。

```bash
cd feishu-attachment-download
npm install        # 安装依赖
npm run dev        # 本地开发，默认 http://localhost:5173
```

## 部署（让插件在多维表格中运行）

插件以 **HTTPS 地址** 加载进多维表格。任选一种托管方式：

### 方式 A：Vercel（最简单，推荐）

1. 把整个 `feishu-attachment-download` 目录推到一个 GitHub 仓库；
2. 在 [vercel.com](https://vercel.com) 导入该仓库；
3. Framework 选择 **Vite**，构建命令保持默认（`npm run build`，输出目录 `dist`）；
4. 部署完成后得到一个 `https://xxx.vercel.app` 地址。

### 方式 B：GitHub Pages / Nginx / 任意静态服务器

```bash
npm run build        # 产物在 dist/
```

把 `dist/` 目录上传到任意 HTTPS 静态托管（GitHub Pages、Nginx、OSS 等），得到站点 URL。

### 方式 C：仅本机临时使用

局域网内用 `npm run dev` 起服务，并把地址暴露为 HTTPS（可用 `ngrok http 5173` 或 `cloudflared tunnel --url http://localhost:5173`）。飞书要求 HTTPS。

## 在多维表格中添加插件

1. 打开一个飞书**多维表格**；
2. 点击右上角 **插件** 图标 → 展开插件面板；
3. 点击 **自定义插件** → **+ 新增插件**；
4. 在输入框填入你部署好的 **HTTPS 地址**（如 `https://xxx.vercel.app`），点击 **确定**；
5. 插件随即在边栏运行，勾选附件字段、填命名规则、点击 **一键下载并打包 ZIP**。

## 使用说明

- **权限**：插件运行时使用你当前登录的账号权限，只能读取你有权访问的记录与附件。
- **附件字段**：会在当前数据表自动列出所有附件字段，默认全选。
- **命名模板**：在输入框直接编写，或点击下方的变量按钮插入。任意字段名也可作为变量（`{字段名}`）。
- **预览**：点击「预览命名（前 5 条）」可查看实际效果。
- **打包下载**：ZIP 名称默认 `<数据表名>_附件_<日期>.zip`，浏览器会自动开始下载。
- **失败处理**：单个文件下载失败会记录到结果区，不影响其他文件；完成后请核对失败清单。

## 常见问题

- **提示“插件只能在多维表格中运行”**：直接用浏览器打开该地址无法连接表格，属正常现象；请按上文在真实多维表格的自定义插件中添加地址。
- **某些文件下载失败**：多为文件体积较大或临时链接过期（10 分钟）。可重新点击一次打包；也可在结果区看到具体失败原因。
- **ZIP 非常大**：浏览器打包会占用内存，超大附件（合计数百 MB 以上）建议分批（先按视图筛选记录）下载。
- **「当前视图」范围**：依赖当前视图的可见记录；若表格开了筛选/高级权限，以视图实际显示为准。
